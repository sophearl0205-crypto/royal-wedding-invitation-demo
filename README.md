# Royal Wedding Invitation Demo

A responsive, editable wedding invitation website template built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Preview locally
Open `index.html` in a modern browser.

## Quick customization
Open `index.html` in VS Code and edit the `WEDDING` object near the bottom:
- `bride` and `groom`: couple's names
- `date`: wedding date/time in `YYYY-MM-DDTHH:MM:SS`
- `dateLabel`: date displayed on the page
- `musicUrl`: optional direct URL to an MP3 you own or have permission to use

Edit the venue, schedule, RSVP deadline, and page copy directly in the HTML. Replace the sample gallery panels with client-approved photos.

## Before using for a real wedding
- Replace all fictional names, dates, venue details, schedule, and gallery placeholders.
- The RSVP form is a front-end demonstration only; it does not store or send responses. Connect a form service or backend before publishing for a real event.
- Add a permitted music file URL if desired.
- Confirm privacy, hosting, domain, and map arrangements with the client.

## Publish
Deploy this static site with GitHub Pages, Netlify, or Vercel.
